# Трансляция «Живого заповедника»: гайд для администратора

Заповедник — мир зверей для стрима. Зрители управляют им командами в чате Telegram, Twitch или
YouTube: берут зверей под опеку, голосуют за погоду, болеют за виды. Игра сама читает чаты и сама
показывает зрителям подсказки. Администратору нужно один раз всё настроить, а потом только
запускать.

Что понадобится:
- компьютер с macOS или Windows;
- Godot 4.6 и папка проекта (пока нет готовой сборки);
- OBS Studio;
- бот Telegram, канал Twitch или API-ключ YouTube — смотря где трансляция.

## 1. Установить и открыть игру

**macOS**
1. Скачайте Godot 4.6 (обычную версию, не .NET) с [godotengine.org](https://godotengine.org/download)
   и перенесите `Godot.app` в «Программы».
2. Получите папку проекта (например, `git clone` или архивом).
3. Откройте Godot → «Импорт» → выберите `project.godot` из папки проекта → «Импортировать и
   редактировать». Первый раз Godot соберёт ресурсы, это займёт минуту.
4. Запуск: кнопка ▶ («Запустить проект», F5) в правом верхнем углу редактора.

**Windows**
1. Скачайте Godot 4.6 (Windows, обычная версия) с [godotengine.org](https://godotengine.org/download),
   распакуйте архив в удобную папку, например `C:\Godot`.
2. Получите папку проекта.
3. Запустите `Godot_v4.6…_win64.exe` → «Импорт» → `project.godot` → «Импортировать и
   редактировать».
4. Запуск: кнопка ▶ (F5).

Можно запускать и без редактора, одной командой (путь к проекту — свой):

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path /путь/к/проекту
```

```bat
C:\Godot\Godot_v4.6.2-stable_win64.exe --path C:\путь\к\проекту
```

## 2. Мастер «Трансляция»

В стартовом меню нажмите **«Трансляция»**. Мастер из трёх шагов запоминает всё сам. Ключи хранятся
только на этом компьютере, в папке настроек игры:
- macOS: `~/Library/Application Support/Godot/app_userdata/Engine of Ecosystem/stream.json`;
- Windows: `%APPDATA%\Godot\app_userdata\Engine of Ecosystem\stream.json`.

### Шаг 1. Чаты

Включите чаты, где пойдёт трансляция. Каждый проверяется своей кнопкой «Проверить».

**Telegram**
1. Кнопка «Открыть BotFather» → в Telegram `/newbot` → имя и логин бота (логин кончается на `bot`).
   BotFather пришлёт токен — вставьте его в поле «Токен бота» и нажмите «Проверить». Должно
   появиться «✓ Бот @… на связи».
2. В BotFather: `/setprivacy` → ваш бот → **Disable**. Без этого бот не видит команды с «!».
   Если privacy поменяли, когда бот уже был в группе, удалите его из группы и добавьте снова.
3. Добавьте бота в группу трансляции (или в группу обсуждения канала).
4. Нажмите «Найти группу» и напишите в группе любое сообщение. Группа появится в списке — нажмите
   «Добавить». Бот слушает только добавленные группы.

Бот отвечает правилами на `!помощь`, `!правила`, `/help`, `/start`: в группе — раз в минуту, в
личке — всегда.

**Twitch** — впишите имя канала, как в ссылке `twitch.tv/имя`, и нажмите «Проверить». Вход не
нужен: чат читается как гость.

**YouTube**
1. «Открыть Google Cloud» → создайте проект → включите **YouTube Data API v3** → Credentials →
   Create credentials → API key.
2. Вставьте ключ и ссылку на эфир. У каждого эфира своя ссылка.
3. «Проверить» находит чат, только пока эфир идёт.

Квота YouTube — 10 000 единиц в сутки. Игра опрашивает чат раз в 8 секунд, этого хватает примерно
на 4 часа эфира в сутки.

### Шаг 2. Картинка для зрителей

**Проще всего, если трансляция в Telegram, — без OBS.** В группе начните обычный видеочат, нажмите
«Экран» и выберите окно игры («Engine of Ecosystem»). Зрители смотрят прямо в группе, а команды
пишут в её чат. Так проверено на телефоне.

**С OBS** — для Twitch, YouTube или трансляции Telegram «Начать с помощью…» (RTMP). Мастер
показывает, что нажимать в OBS для вашей системы: кнопка «Подсказки для: Mac/Windows»
переключает. Кратко:
1. В «Источниках»: «+» → захват окна игры. На Mac: «Захват экрана macOS» → «Захват окна»;
   на Windows: «Захват окна». Название окна копирует кнопка «Скопировать название окна».
2. Видео: 1920×1080, 30 кадров/с, источник растянуть по экрану. Вывод → «Расширенный»: x264
   (или Apple VT H264), CBR, 4500 Кбит/с, интервал ключевых кадров 2 с; звук AAC 160 Кбит/с.
3. Трансляция:
   - **Telegram:** в группе «Трансляция» → «Начать с помощью…» → «URL сервера» и «Ключ
     трансляции» вставить в OBS (Сервис «Настраиваемый…»);
   - **Twitch, YouTube:** Сервис нужной платформы → «Подключить аккаунт».
4. Окно игры не сворачивать: свёрнутое окно не рисуется. **На Mac не включать полноэкранный
   режим:** полноэкранная игра — отдельный рабочий стол, и пока вы в OBS, она не рисуется,
   трансляция замирает. Заповедник сам открывается в окне на весь экран; окна поверх не мешают.

На Mac при первом запуске OBS попросит доступ к записи экрана: Системные настройки →
Конфиденциальность и безопасность → Запись экрана → OBS.

### Шаг 3. Запуск

Мастер показывает, какие чаты готовы.
- **«Картинка: горизонтальная / вертикальная».** Вертикальная (9:16) — для зрителей с телефонов:
  окно игры встаёт вертикально, без рамки и заголовка; текст и звери крупные; на экране только
  сезон, числа видов, короткая панель (где правила, голосование, последняя новость) и короткая
  карточка зверя. Мини-карты, ленты и метки над зверем нет. В OBS для неё холст 1080×1920. Во
  время эфира переключается клавишей **F10** (так же окно возвращает рамку).
- Курсор мыши прячется сам, если мышь не двигается 2 секунды, — в трансляцию он не попадает.
- «Продолжить мир» — с последнего сохранения заповедника;
- «Новый мир» — начать заново.

Потом в OBS «Начать трансляцию», а в Telegram ещё и «Начать трансляцию» в группе.

Мир сохраняется каждые две минуты в свои слоты (обычная игра их не трогает). Esc — пауза.

## Каждый следующий раз

1. Запустить игру → «Трансляция» (мастер сразу откроется на шаге «Запуск») → «Продолжить мир».
2. В OBS «Начать трансляцию».

Для YouTube перед каждым эфиром вставьте новую ссылку на шаге 1.

## Если что-то не так

Пока какой-то чат не читается, на панели заповедника вверху слева горит красная строка.

| Что видно | Что сделать |
|---|---|
| «Telegram: Неверный токен бота» | скопируйте токен из BotFather заново (`/token` или `/revoke`) |
| «Этого бота уже читает другая программа» | закройте второй экземпляр игры или мост `bridge.py` с тем же ботом |
| Бот на связи, но команды не доходят | `/setprivacy` → Disable и заново добавить бота в группу; группа должна быть в списке «Группы» |
| «Квота YouTube на сегодня кончилась» | ждать: игра сама попробует снова; или реже опрашивать (`min_interval_seconds` в `stream.json`) |
| «Эфир сейчас не идёт» | эфир YouTube ещё не начат или ссылка от прошлого эфира |
| Картинка замирает, пока вы в OBS (Mac) | игра во весь экран: F11, чтобы вернуть окно |
| Окно в вертикальном режиме встаёт не 9:16 | это раскладка окон macOS (или программа для неё) прижимает окно к половине экрана; растяните окно вручную — панели подстроятся |
| OBS шлёт поток, а в Telegram пусто («Oops! Telegram doesn't see any stream») | покажите окно игры через «Экран» в видеочате группы — это работает без OBS. Или: подождать 15–20 с и открыть трансляцию с телефона; проверить вывод (CBR 4500, ключевые кадры 2 с, 30 кадров/с); перезапустить: «Остановить» в OBS, завершить трансляцию в Telegram, снова «Начать с помощью…» со свежим ключом |
| В OBS чёрный экран (Mac) | дать OBS доступ к записи экрана и перезапустить OBS |
| В OBS чёрный экран (Windows) | в свойствах источника «Метод захвата: Windows 10 (1903 и новее)» |

Команды зрителей и правила заповедника — в `tools/stream_bridge/README.md` (раздел «Команды
зрителей») и в `data/config/reserve.json`.

Мост `tools/stream_bridge/bridge.py` больше не нужен: игра читает чаты сама. Он остаётся для
случая, когда чат читается на другом компьютере. Не запускайте его вместе с игрой на том же боте:
команды придут дважды, а Telegram отдаст бота только одному.
