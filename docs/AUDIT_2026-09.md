# Engine of Ecosystem — аудит и направления развития

## Context

Запрос: проанализировать возможности AI, графику, поведение, реалистичность и перфоманс; дать геймдизайнерскую оценку и предложить механики; проанализировать рынок, аналоги, best practice и предложить направления развития.

Проект: Godot 4.6, GDScript, ~18k строк. Экосистемная песочница: травоядные (стада), хищники (пары), падальщики (стаи), трава, вода, туши, сезоны, день/ночь, 4 биома + высоты + препятствия, utility‑AI с объяснимыми решениями, детерминизм, save/load, камерный LOD с «спящими» секторами (coarse ecology). Игровых целей нет: игрок наблюдает, ставит паузу/скорость, следует за животным, включает отладочные оверлеи.

Метод: три параллельных аудита кода (AI/поведение/реализм, графика/перфоманс, рынок) + геймдизайн‑агент + скриншоты реальной сборки (снято через `scripts/dev/capture.gd` из копии проекта в scratchpad; сам worktree не тронут). Машина: Apple M2, 8 ядер, 16 ГБ, Godot 4.6.2, рендер `gl_compatibility`.

Скриншоты: [docs/audit/hud.png](audit/hud.png) (HUD с перфоманс‑цифрами), [docs/audit/top_close.png](audit/top_close.png) (вид сверху крупно), [docs/audit/iso_close.png](audit/iso_close.png) (изометрия).

## 1. AI и поведение

### 1.1 Архитектура (как есть)
- Три слоя: строковый `agent.state` (исполнение), FSM `ai_state` (`alive/panic/engaged/dead`), utility‑`current_action` (12 действий). Реально всё держится на нетипизированном `agent.state`, который пишут ~20 мест — это четвёртая, недокументированная FSM.
- Решения раз в 3 тика (6 Гц) на LOD0, реже на LOD1/2; гистерезис: бонус текущему 0.10 + порог переключения 0.15 = 0.25 сырого счёта; min commitment 6 тиков.
- Сильные стороны: `SpeciesRegistry` (виды через data, слоты, обратные индексы), `Climate` как чистая функция времени, механизм veto для «холостых» действий хищника, строки причин в инспекторе, патруль хищника по секторному «давлению добычи».
- Структурные слабости (файлы:строки в отчёте агента):
  - Панический путь травоядного захардкожен в `herbivore.gd:54-72`: `FleeUtilityEvaluator`, PANIC‑policy и веса `flee_to_safe_area` в `balance.json:96-102, 200-206` — мёртвый конфиг.
  - `join_herd` фактически = `explore` (гейт `hunger < 12`), `herd_proximity` инвертирован (`herbivore_ai.gd:161`).
  - Пороги отдыха абсолютные (26/34) при `max_energy` 100/150/90 → хищник отдыхает только ниже 17%.
  - `PredatorAI` без `_config_key()` — второй хищник разделит тюнинг первого. `Scavenger extends Herbivore`.
  - Биомы захардкожены строками в `utility_context_factory.gd:25-40`.
  - Мёртвое: `REPRODUCE` без evaluator, `get_state_modifier` — заглушка, `health_ratio` всегда 1.0, `water_sources` в `world.json:270-361` не читается (генерируется ~52 источника, README говорит 18).

### 1.2 Что игрок увидит как «неправильно»
| Симптом | Причина |
|---|---|
| Хищник убивает и сразу бросает тушу с 66/150 мяса | одномоментный укус 84 + `gorge` → энергия 150 → отпускает тушу (`predator.gd:305-313`) |
| Сытый хищник продолжает охотиться (surplus killing) | `can_continue_feeding()` включает HUNT/chase → gorge‑клауза держит `feeding_allowed` |
| Хищники бесконечно гоняют падальщиков | спринт падальщика 132 > хищника 128; 14 с гарантированного провала |
| Стадо «взрывается» радиально, а не бежит вместе | `_flee` игнорирует соседей, нет cohesion/alignment |
| Стада не похожи на стада во время еды | вес стада 0.15 vs seek 1.3; травоядное 90% времени в graze |
| Мерцание паника/спокойствие | `threat_memory_seconds 2.0` + сброс пути при каждом выходе |
| Бросают еду/воду ради спаривания; один из пары стоит столбом | `_attempt_reproduce` до селектора; `stop_motion()` у старшего id |
| Новорождённые — взрослые | нет ювенильных параметров, полная скорость/тело/энергия |
| Хищник идёт в пустоту | центроид «пара + все потомки» |
| Ночь — резня | perception ×0.55 → радиус тревоги 66 при контакте 38 |
| Все идут к одной клетке травы | секторный кандидат относительно центра сектора |

### 1.3 Экологический реализм
- Три трофических уровня реально есть; окно 12 с эксклюзивной падали для хищника — лучшая экологическая идея проекта.
- **Нет ёмкости среды**: трава ~8.5 M биомассы, 240 травоядных едят 0.07% от потенциального отрастания. Нет bottom‑up регуляции, нет осцилляций Лотки–Вольтерры.
- Рождаемость перекрывает хищничество на порядок (≈2.6 рождений/с против ≈0.36 убийств/с); единственный тормоз — `max_age 220 с`.
- Жизнь = 1.8 суток = 1.8 сезона. Никто не проживает год; сезоны не влияют на размножение.
- Энергобюджет хищника: одно убийство = 1.4 полной шкалы энергии, провальная погоня < половины. Охота почти бесплатна.
- Отсутствует полностью: генетика/вариативность (потомки byte‑идентичны шаблону), обучение, социальная структура (доминирование, территория, семьи, деление/слияние групп), возрастные классы, болезни, миграция, разнообразие растений, конкуренция, погодные события, динамика воды (источники бесконечны, радиус поиска воды 1920 при карте 14400).

### 1.4 Детерминизм и спящие секторы
- Инвариант «спящий путь не трогает rng» **нарушен**: `_random_sex()` для рождённых в спящем секторе (`world_state.gd:3086`). Движение камеры меняет число вызовов rng → рассинхрон.
- Детерминизм держится только при идентичном LOD‑контексте (wander вызывает rng только на полных тиках).
- Спящее хищничество — тип I без насыщения: 1 хищник среди 20 жертв убивает в ~14× больше нужного; спящие стада вымирают быстрее наблюдаемых.
- `_sync_dormant_records_with_aggregates` каждый шаг перезаписывает индивидуальные hunger/thirst/energy/age средним → стадо после пробуждения пересекает пороги синхронно.
- Тест детерминизма: 2 агента, 18 тиков, без климата/LOD/рельефа — ничего из перечисленного не ловит.

### 1.5 Топ‑10 улучшений AI (impact/effort)
1. Стадное бегство (cohesion+alignment в `_flee`, safe‑biome в выборе точки бегства) — high/low.
2. Починить убийство→кормление (укус по рейту, не отпускать тушу ради спаривания) — high/low.
3. Закрыть утечку `gorge_below_energy_threshold` в охоту; отдельный `satiation_energy` — high/low.
4. Оживить PANIC/flee utility‑путь; `threat_memory_seconds` > 2 — high/medium.
5. Желудок/жировой запас вместо фиксированного укуса; пороги как доли от max — high/medium.
6. Спящее хищничество тип II + не гомогенизировать записи — high/medium.
7. Восстановить rng‑инвариант спящего пути; полноценный тест детерминизма с LOD — medium/low.
8. Индивидуальная вариативность + минимальный геном (скорость, зрение, метаболизм, пороги, наследование с мутацией) — high/medium‑high. **Ключевое изменение «скринсейвер → экосистема».**
9. `join_herd` + динамическое членство в группах (fission/fusion) — medium/medium.
10. Координация хищников (общая цель/фланг) + «догоняемость» в выборе жертвы — medium/medium.

Мелкий баг, найденный при захвате: при завершении процесса рабочий поток ещё обращается к агентам после выгрузки скриптов (`Invalid access 'stuck_timer'`, `Nonexistent function 'export_runtime_state'`) — гонка shutdown в `simulation_manager.gd`/`simulation_worker.gd`.

## 2. Графика

### 2.1 Что есть
- Пайплайн: TileMapLayer (орто: 2 слоя + сабдивизии + варианты; изо: y‑sort, высота через alternative tiles с юбками) + MultiMesh на вид + `scene_sprite_batch` (рантайм‑атлас для глобальной сортировки) + 3 маленьких шейдера. Всё `unshaded`.
- Анимация — самая сильная часть: Catmull‑Rom по 4 тикам, шаг по пройденному расстоянию (нет скольжения на x10), 4 направления в экранном пространстве с гистерезисом, масштаб по возрасту, idle‑bob с фазой по id, тени на «земле».
- Реальный арт: животные CraftPix (7×20 кадров 32 px), пропсы CraftPix, terrain Kenney 16 px, UI CraftPix ×3. Плейсхолдеры: **изометрический terrain, orto `terrain_atlas.png`, туши, тень**.
- День/ночь через `CanvasModulate` по 7 ключам; сезонный `tint` в `world.json` **никем не читается**.
- UI: parchment‑тема аккуратная (7/10), карточка выбранного, тег над животным, климат‑бар, минимапа. Debug‑панель — отличный dev‑инструмент (9/10), скрыт за Tab.

### 2.2 Дефекты
- **Двойная отрисовка**: `scene_sprite_batch` добавлен как сиблинг, а пер‑видовые MultiMesh не скрыты → каждый агент растеризуется дважды, глобальная сортировка выброшена для хищников/падальщиков, ~2400 RS‑round‑trip/кадр на 400 агентов (`agent_renderer.gd:455-457, 186, 263`).
- Анимация смерти есть в атласе, но недостижима: `refresh()` берёт только живых.
- Истощение травы невидимо (только debug‑оверлей). Вода по умолчанию **не рисуется** (`debug.json:31 show_water_overlay:false`).
- Нет автотайлинга/переходов биомов (лестница 96‑юнитных квадратов — видно на скриншотах), статичные деревья, нет частиц/света/твинов/звука, нет фидбэка на охоту/смерть/рождение.
- Изометрия: seam `WorldProjection` продакшн‑качества, но контент — прототип: плейсхолдер‑земля, клик без коррекции высоты (`world_view.gd:47`), камера‑прямоугольник на минимапе неверной формы, ×1.7 тик и ×2.3 render CPU. Три места спорят, какая проекция дефолтная.
- Смешанный RU/EN в одном меню; нет i18n.
- **Лицензия**: `assets/craftpix/` (104 .aseprite, 119 .psd) закоммичены — редистрибуция запрещена, сам `assets/LICENSE.txt` предупреждает. Блокер публикации репо.
- Скриншоты подтверждают: стада — плотные «кляксы» с наложением спрайтов; масштаб деревьев (×1.8) спорит с животными; падальщики — красные кляксы‑плейсхолдеры; ландшафт читается как цветные прямоугольники.

## 3. Перфоманс

### 3.1 Измерения
- HUD на старте (large, 336 агентов, M2): **Actual speed 0.27x**, Tick p95 185 мс, Step avg 126 мс, LOD0/1/2 = 18/174/144. Это первая секунда (прогрев), но показательно.
- Headless‑бенчмарки соседней ветки (large, ~400 агентов, 18 Гц): LOD off — tick p50 46–167 мс (0.3–1.09x); **LOD on — 11.9 мс (4.35x)**. LOD даёт ~4×.
- GUI (visual_audit): камера на стаде → tick p50 96–109 мс, **actual speed 0.50**, за окно теряется 1–2.7 с симуляции (`MAX_SIMULATION_STEPS_PER_FRAME=2` молча выбрасывает время). Render CPU 0.4–3.5 мс — рендер не узкое место.
- Разбивка LOD off: `phase_agents` 88% (травоядные 53% из них, `ai_context_build` 24%). LOD on: секторы+спящая экология становятся 47% тика.

### 3.2 Архитектурные находки
- Worker: `Thread.new()` **каждый тик** (18/с), без пула/семафора. Передача состояния — O(N) Dictionary на агента + копия всей сетки травы (12 750 float) + глубокие копии туш/секторов/событий, а на main‑thread — полная пересборка spatial grid «для оверлеев».
- `_resolve_agent_overlap` O(N·соседи) каждый тик, не гейтится LOD, с 9‑итерационным бинарным поиском на коррекцию.
- A* на Dictionary‑куче и Dictionary g/f; эвристика с двумя `sqrt` дважды на узел. Кэш путей LRU 768, хит 94–96% — хорошо. Локальный обход строит `AStarGrid2D` 25×25 на каждый вызов.
- Телеметрия не бесплатна: ≥800 `get_ticks_usec()` на тик, 42‑ключевой Dictionary пересоздаётся каждый тик, `get_snapshot()` делает deep copy ~150 ключей 18 раз/с при UI 3.6 Гц.
- `query_carcasses` — линейный скан без индекса.
- Баг: `telemetry_logger.gd:66` пишет metrics CSV без экранирования — вложенный dict со запятыми сдвигает колонки, файлы непарсибельны.

### 3.3 Потолок и путь к 10×
- Честный потолок сейчас: ~400 агентов с LOD на large; в GUI уже 0.5x у стада. Профили бенчмарка 750/1500 объявлены, но ни разу не прогнаны.
- Быстрые выигрыши (GDScript): постоянный worker‑поток; двойная буферизация вместо копий; LOD‑гейт overlap; A* на Packed‑массивах; индекс туш; телеметрия по выборке; snapshot только на UI‑каденции.
- 10× (≈4000): **GDExtension/C++ или C# для agent tick/perception/A\***, struct‑of‑arrays на Packed‑массивах, flow fields вместо per‑agent A* (цели общие: вода, трава секторов, давление добычи), compute shader для травы (требует Forward+/Mobile, что заодно открывает 2D‑свет).

## 4. Геймдизайн

### 4.1 Что весело сейчас и что убивает интерес
- Первые 90 секунд приятные: стада плывут по карте, лисы режут их, тинт дня/ночи, сезонная шкала. Читается как «живое».
- Единственный момент инсайта — клик по животному и `Decision: dropped graze (threat); flee_to_safe_area` в инспекторе. Объяснимый AI — самый недоиспользованный актив проекта.
- Детерминизм (seed + пресет) — скрытый «экспериментальный» глагол: тот же seed при `drought` vs `lush` сравним. Игроку об этом не говорят.
- Тест Brown/Koster: игрок **узнаёт** одно правило («лисы гонят оленей, олени разбегаются») за 3 минуты; **решает** только куда смотреть; **не предвкушает** ничего — смерти без фидбэка, все животные одинаковы и живут 220 с, за которым следил — умер до привязанности.
- **Интерес умирает на 6–8 минуте**: график населения плоский, лог событий — JSON, рычагов нет. HUD — инженерный прибор; меню на русском, HUD на английском.

### 4.2 Кандидаты core loop
| | A. Nature documentary / генератор историй | B. Steward / god‑game | C. Evolution lab |
|---|---|---|---|
| Фантазия | оператор и рассказчик фильма о природе | смотритель заповедника; экосистема — антагонист | Дарвин с секундомером |
| Минута | выбрать, назвать, следовать; тикер историй; «моменты» | читать индикаторы угроз, тратить редкую силу, смотреть последствие на x4 | гистограммы трейтов, геном vs популяция, давление отбора |
| Сессия | «глава» на сезон, итог сезона, династии | сценарий с целью и бюджетом сил | челлендж «средний спринт > 130 за 20 поколений» |
| Переиспользует | EventBus (родители в `AgentReproduced`, `cause`+`other_agent_id` в `AgentDied`), reason‑теги, focus flock, selection card, climate, SaveSystem | presets.json + `_merge_into`, `spawn_agent/kill_agent`, ячейки травы, вода, StatsSystem snapshot | per‑instance конфиги агента (перебор почти бесплатен), `_flush_pending_spawns`, StatsSystem |
| Нужно построить | реестр линий (события капятся 4096, спящие рождения с id −1 → пины форсить LOD0), имена, композитор историй, детектор «заметных», фидбэк, длинная жизнь + ювенилы | очередь команд через `SimulationWorker.step()` (presentation‑копия неизменяема), лог команд в сейв, DSL целей, UI сил, индикаторы; **предпосылка — ёмкость среды и конечная вода** | геном/мутации/наследование, сэмплинг трейтов, **спящие агрегаты должны нести среднее/дисперсию генома** |
| Риск | пассивно, усиливает изъяны AI, без fail‑state держится на новизне | балансировка реальна; «5 лет» = 40 мин на x1 при GUI 0.5x | невидимо без A; конфликт со спящей экологией — самый тяжёлый инженерный пункт |

### 4.3 Рекомендация: A → B поэтапно, C как P2
1. Дифференциаторы сборки — объяснимые решения и детерминизм; оба — активы **читаемости**. Механики A дёшевы, не требуют новой симуляции и нужны любому другому лупу.
2. У A нет решений; B — самый дешёвый генератор решений: spawn/kill/patch уже функции, пресеты — готовый формат сценариев без целей.
3. Предпосылки B (ёмкость среды, конечная вода, ювенилы, длинная жизнь) — те же пункты, что AI‑аудит назвал причиной скуки. Это не доп. работа, это и есть игра.
4. C конфликтует со спящей экологией и требует длинных сессий — третий акт.

### 4.4 Механики (S < 1 дня, M 2–5 дней, L 1–2 недели)
**P0 — фундамент (читаемость + ставки)**
| # | Механика | Хуки | Размер |
|---|---|---|---|
| 1 | Имена животных + пины (до ~8, форс LOD0, сектор не спит) | `agent_readout.gd` `title()`, новый `scripts/story/lineage_registry.gd`, правило форса выбранного в `world_state.gd` | M |

### 4.5 Сценарии и DSL целей
Файл `data/config/scenarios.json`: `{id, title, brief, selection:{map_size,mix,scenario,rules,difficulty}, patch, powers:{budget,allowed}, start_camera, goals[]}`. `selection` идёт через существующие группы, `patch` — ещё один `_merge_into`.

DSL (оценка на каждом snapshot, 18 тиков, main thread):
```
goal := {id, label, kind: win|lose|bonus, when: cond}
cond := {metric, op, value} | {sustain: cond, seconds} | {by: {years|season|seconds}, cond}
      | {after: {...}, cond} | {all: [...]} | {any: [...]} | {not: cond}
```
Метрики — ключи snapshot (`herbivore_population`, `deaths_thirst_herbivore`, `hunt_success_rate`, `grass_biomass_by_biome.meadow`, `season_index`, `time_seconds`) + производные (`years`, оконные rate `@window:120s`, `lineage.<tag>.generations`, `pinned.<tag>.alive`, `powers.used`).

Сценарии: 1) **Первая зима** (туториал, старт осенью, win ≥ 0.6 популяции к весне); 2) **Слишком много лис** (sustain обоих видов 3 года; relocate ×3, cull ×4); 3) **Долгая сушь** (0 смертей от жажды за лето; waterhole ×1; нужна конечная вода); 4) **Горный перевал** (highlands, chokepoints; relocate ×1); 5) **Экономика падали** (парный с/без падальщиков; `carcasses_expired ≤ 10`); 6) **Матриарх** (пин, `lineage.generations ≥ 3` до 2 лет; shelter ×2); 7) **Ночные охотники** (следовать за парой лис, 5 убийств до зимы, бонус — без `timeout`); 8) **Гипотеза** (предсказать, кто первым достигнет пика; ноль новой симуляции).

### 4.6 Онбординг, первые 10 минут
Меню: Play (список сценариев, «Первая зима» выделена) / Continue / Sandbox (текущие 6 групп + seed, «Advanced») / Help, один язык. 0:10 — бриф в три предложения, камера на стаде, одно животное запинено и названо, чип цели. 0:30–2:00 — подсказки по одной («кликни», «F — следовать», «отдали — ускоришь»), первый лис = тост «момент», охота с фидбэком и строкой в story log. 2:00–5:00 — трава редеет под стадом, первое рождение. 5:00–8:00 — зима, тинт, чип цели желтеет, игрок **ждёт весну**. 8:00–10:00 — экран итога с кривой и полосами сезонов, открывается следующий сценарий с первой силой.

### 4.7 Что убрать/спрятать
Debug‑панель за `developer_mode` в `debug.json`; оверлеи 14 → 3 игровых (трава, вода, угроза); Step/LOD/Export/frame‑stats — dev‑only; изометрия — Experimental; 6 дропдаунов + seed — в Sandbox; JSON‑лог → story log; один язык; x10 через zoom‑out; красные падальщики — арт или `no_scavengers` в туториалах.

### 4.8 Метрики плейтеста
Есть: длина сессии/лет, гистограмма скорости (добавить `SpeedChanged`), популяции, смерти по причинам, `hunt_fail_*`. Добавить как `PlayerAction`: выборы/пины/длительность слежения и «довёл ли пин до смерти» (привязанность), клики по story log и тостам, силы на сценарий и латентность «индикатор → сила», исход/ретраи/точность гипотезы, нажатия Tab в non‑dev (если ищут debug — HUD не справляется), время zoom‑out vs in. Качественный гейт: через 15 минут спросить «почему стадо у брода уменьшилось?» — причинный ответ = читаемость работает.

### 5.4 Best practice (источники)
- **Story generator, не симуляция**: Tynan Sylvester, GDC 2017 «RimWorld: Contrarian, Ridiculous, and Impossible» — RimWorld спроектирован как генератор историй; AI Storyteller выбирает события по живой статистике мира (pacing, не рандом). https://media.gdcvault.com/gdc2017/Presentations/Sylvester_Tynan_RimWorld_Contrarian_Ridiculous.pdf
- **Читаемость = продукт**: Chris Hecker, Structure vs Style / Liner Notes for Spore — глубокие системы, которые игрок не видит, не существуют. https://www.chrishecker.com/Structure_vs_Style
- **Utility AI**: Dave Mark, Infinite Axis Utility System (curve‑considerations, compensation factor, weighted‑random среди top‑N, чтобы животные не были роботами). https://www.gameai.com/iaus.php ; GDC 2013 https://www.gdcvault.com/play/1018040/
- **Лотка–Вольтерра в играх**: классическая модель нейтрально устойчива и дрейфует к вымиранию; стабилизаторы — небольшая иммиграция жертв, страх/vigilance‑trade‑off, взаимные помехи хищников, пространственно‑стохастическая формулировка (наша решётка уже даёт это). https://www.nature.com/articles/s41598-018-25436-2 , https://arxiv.org/pdf/0704.0512 . Дизайн‑следствие: миграционные события, штраф скученности хищников и ось «страх» в utility — одновременно стабилизаторы и нарративный контент.
- **Толпы/LOD**: AC Unity — 10 000 видимых NPC на ~40 реальных AI‑агентах (GDC 2015). https://gdcvault.com/play/1022411/ ; ECS даёт ~10× над объектом‑на‑агента. Наш подход (полный AI только для видимых/запиненных, статистика для остальных) — каноничный.
- **Телеметрия для баланса**: инструментировать демо (time‑to‑quit, последнее увиденное событие, нетронутые системы) и использовать Next Fest как датасет.
- Ранжированный по силе свидетельств набор удержания: **имена + древо > листаемая/скриншотабельная хроника > сценарии с win‑условиями > божественные силы с видимыми последствиями > скорости > объясняющие оверлеи > моддинг**.

## 6. Рекомендованные направления и roadmap (итог)

### 6.1 Диагноз в одну строку
Симуляционное ядро и инструментарий сильнее, чем игра вокруг них: объяснимый AI, детерминизм, LOD/спящая экология и телеметрия — активы уровня «движок», но игроку они не видны, а экология внутри не имеет ограничений (трава и вода бесконечны, все животные одинаковы, жизнь короче сезона), поэтому через 6–8 минут смотреть не на что и делать нечего.

### 6.2 Направление
**«Смотритель заповедника»**: читаемый генератор историй о природе (имена, династии, story log) + скупые интервенции и сценарии с целями поверх честной экологии. Генетика/эволюция — третьим этапом, как долгосрочный рычаг и хук для evolution‑аудитории.

### 6.3 Roadmap (порядок важен: каждая фаза делает следующую осмысленной)

**Фаза 0 — гигиена и блокеры (≈1 неделя)**
- Вынести `assets/craftpix/` из VCS (лицензия). Убрать двойную отрисовку агентов. Исправить CSV‑экспорт метрик. Постоянный worker‑поток вместо `Thread.new()` на тик; snapshot deep‑copy только на UI‑каденции. Мёртвый код/конфиг и stale‑доки из аудитов. Гонка shutdown воркера. Восстановить rng‑инвариант спящего пути + расширить тест детерминизма.

**Фаза 1 — честная экология (≈3–4 недели)**
- AI‑топ‑10 №1–7: стадное бегство, kill→feed, gorge‑утечка, живой PANIC‑путь, желудок/пороги как доли, спящее хищничество тип II без гомогенизации.
- Ёмкость среды: трава, которая реально кончается (пересчитать `max_biomass`/regrowth × площадь), вода с объёмом и сезонным пересыханием, ювенильный класс, жизнь 2–3 года, сезонное размножение.
- Критерий готовности: на seed 3 без вмешательств появляются осцилляции хищник–жертва и зимние бутылочные горлышки; стадо бежит как стадо.

**Фаза 2 — читаемость (≈3 недели)**
- Имена + пины, реестр линий/древо, story log из EventBus с reason‑тегами, фидбэк смерти/охоты/рождения, панель стада, индикаторы угроз, трава/вода видны на тайлах, сезонный tint, zoom‑out = fast‑forward, dev‑панель за флагом, один язык UI.
- Критерий: игрок через 15 минут отвечает, *почему* стадо уменьшилось.

**Фаза 3 — agency (≈3–4 недели)**
- Очередь команд через worker + лог в сейв, 5 сил, scenario runner + DSL, 8 сценариев из §4.5, итог сезона, «моменты».
- Критерий: сценарий «Слишком много лис» проходится и проигрывается по‑разному в зависимости от решений.

**Фаза 4 — глубина и масштаб (по итогам плейтеста)**
- Индивидуальная вариативность/наследование (спящие агрегаты несут средние трейтов), территории/миграция, стайная охота.
- Перфоманс: LOD‑гейт overlap, A* на Packed‑массивах, индекс туш; при цели > 1000 агентов — GDExtension/C# для agent tick + SoA + flow fields.
- Графика: автотайлинг биомов, вода‑шейдер, покачивание пропсов, арт для туш/падальщиков/изометрии; 2D‑свет после ухода с `gl_compatibility`.
