# Живой заповедник на трансляции

Игра в режиме заповедника показывает мир для стрима. Зрители влияют на него командами в чате
Twitch и YouTube. Мост `bridge.py` читает чаты и передаёт команды игре на локальный порт.

```
Twitch-чат ─┐
            ├─ bridge.py ──► 127.0.0.1:47821 ──► игра (--reserve) ──► окно ──► OBS ──► стрим
YouTube-чат ┘
```

Ключ трансляции (stream key) вводится только в OBS. Мосту нужны лишь имя канала Twitch, а для
YouTube — API-ключ и id эфира.

## 1. Запустить заповедник

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path /путь/к/проекту -- --reserve
```

- **Без `--fresh`** мир продолжается с последнего сохранения заповедника. Сохраняется каждые
  2 минуты в свои слоты `reserve_a/b.dat`; «Продолжить» в обычной игре их не видит.
- **С `--fresh`** начинается новый мир.
- Мир, зерно, частота сохранений, голосования, фонды и темп камеры задаются в
  `data/config/reserve.json`.

Камера работает сама: смерти и охоты, пришлые звери, подопечные по очереди, стадо в фокусе.
Esc, пауза и скорость работают как обычно.

## 2. Мост чата

1. Скопируйте `bridge.example.json` в `bridge.json` в этой же папке. `bridge.json` в git не
   попадает, ключи остаются только у вас.
2. **Twitch:** впишите `"channel": "имя_канала"`. Чат читается анонимно, без входа.
   - `oauth_token` и `nick` нужны, только если чат закрыт для гостей.
3. **YouTube:** `"enabled": true`, `api_key` и `video_id` (см. ниже).
4. Запустите мост:

   ```bash
   python3 tools/stream_bridge/bridge.py
   ```

   - Мост можно запускать до игры: он подождёт и подключится сам.
   - `--dry-run` печатает команды вместо отправки, удобно для проверки чата.
   - Нужен Python 3.9+, без сторонних пакетов.

В игру уходят только сообщения, начинающиеся с «!». Обычные разговоры чата в неё не попадают.

### API-ключ YouTube

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект.
2. «APIs & Services» → «Library» → **YouTube Data API v3** → Enable.
3. «Credentials» → «Create credentials» → **API key**. В «API restrictions» ограничьте ключ
   YouTube Data API v3.
4. `video_id` — id эфира: часть ссылки после `watch?v=`, `youtu.be/` или `youtube.com/live/`. У
   каждого нового эфира свой id.

**Квота.** Один опрос чата стоит 5 единиц из 10 000 в сутки на проект. Интервал
`min_interval_seconds` ≈ **1,8 × часов эфира в сутки**:

| Эфир в сутки | Интервал |
|---|---|
| 4 ч | 8 с (по умолчанию) |
| 12 ч | 22 с |
| 24 ч | 44 с |

- Чтобы опрашивать чаще круглосуточно, нужна заявка на увеличение квоты (форма «YouTube API
  Services — Audit and Quota Extension»).
- Если квота кончилась, мост ждёт 10 минут и пробует снова.
- Если YouTube отвечает 401/403 на чтение чата, нужен OAuth-токен аккаунта канала
  (`oauth_token`, scope `youtube.readonly`). Мост его принимает, но не получает сам.

## 3. OBS

1. **Источник.**
   - macOS: «Захват экрана macOS» → способ «Захват окна» → окно игры.
   - Windows: «Захват окна» или «Захват игры».
2. **Размер.** Окно игры 1920×1080 или 1600×900. Холст и вывод OBS — 1920×1080, 30 кадров/с.
3. **Ключ трансляции.** Настройки → Трансляция → Twitch или YouTube. Ключ остаётся в OBS.
4. **Окно не сворачивать.** Окно игры должно оставаться видимым: свёрнутое macOS не
   рисует. Удобно держать его на втором мониторе или отдельном рабочем столе.

## Команды зрителей

| Команда | Что делает | Ограничение на зрителя |
|---|---|---|
| `!имя Ветка` | взять под опеку зверя у стада в кадре и назвать его (один живой подопечный) | раз в 30 с |
| `!моё` | камера покажет вашего подопечного | — |
| `!1` `!2` `!3` | голос за событие (дождь, сушь, стужа, буйная трава, пришлые звери) | один голос за раунд, до закрытия можно передумать |
| `!водопой` `!повести` `!отстрел` | силы смотрителя для стада в кадре; водоёмов не больше 12, отстрела нет, пока лис меньше 16 | раз в 3 мин, плюс общий откат силы (отстрел — 4 мин) |
| `!олени` `!лисы` `!волки` `!зайцы` | болеть за вид; фонд с самым большим числом активных болельщиков раз в 5 минут получает подарок | раз в минуту |

- **Голосование** открывается каждые 4 минуты на минуту.
- **Пришельцы** из голосования и фондов не приходят к виду, которого уже много (оленей 450,
  лис 40, тетеревов 200, волков 24, зайцев 150).
- **Спасение вида.** Если вид почти вымер (оленей меньше 40, лис меньше 6, тетеревов меньше 15,
  волков меньше 4, зайцев меньше 10), с края карты сами приходят новые звери, не чаще раза в 10 минут на вид.
- **Время** считается временем мира: на паузе оно стоит.
- **Имена** подопечных — только буквы, пробел и дефис, до 16 знаков, без слов из списка запретных
  (`reserve.json` `names.blocked`).
