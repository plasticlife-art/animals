# Free Top-Down Hunt Animals Pixel Sprite Pack

CraftPix freebie. License: https://craftpix.net/file-licenses/ - the game may use
the art, but the source files must not be redistributed, so they are not in this
repository.

Download: https://craftpix.net/freebies/free-top-down-hunt-animals-pixel-sprite-pack/

Unpack it here so that `PNG/Without_shadow/` exists, then run `python3 tools/build_pack_atlases.py` to rebuild the tracked
atlas. The `.gdignore` beside this file keeps Godot from importing the raw files
or exporting them with the game.
